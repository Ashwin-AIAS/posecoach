# /run-colab

Step-by-step guide to run the P01 Colab notebook from scratch.

## Steps
1. Go to [colab.research.google.com](https://colab.research.google.com) → Open `PoseCoach_P01_Colab.ipynb` from Google Drive (`GYMVISION AI/`).
2. Runtime → Change runtime type → **T4 GPU** → Save.
3. Run Steps 1–12 in order (each cell caches progress to `MyDrive/GYMVISION AI/`).
4. After Colab finishes, run `/sync-drive` for local file sync instructions.
